# Codebase Map — HackIT Commit Rush

## Overview
This repository contains 67 student project submissions for the **HackIT Commit Rush** event.

## Core Directories & Projects
- `LangChain_Form_Automation_Agent`: AI agentic form automation workflow.
- `AI_Data_Analyst_Agent`: Natural language data analysis assistant.
- `DeepLearning_Invoice_PDF_Extractor`: PDF invoice data extraction pipeline using Gemini.
- `OpenAI_Syntax_Generator`: Automated syntax generator script.
- `Blood_Donation_Management_System`: Django blood bank management system.
- `Hostel_Room_Allocation_System_*`: Hostel room allocation & fee tracking modules.
- `University_Course_Enrollment_Portal_*`: Course catalog & registration portals.
- `Student_Attendance_Marks_Dashboard_*`: Student marksheets & attendance dashboards.
- `Student_Grade_Mark_Management_System_*`: Grade calculation and report systems.
- `Library_Book_Issuance_Portal_*`: Library catalog & issuance portals.
- `Library_Catalog_Management_System_*`: Library management portals.

## Global Environment & Configuration
- `.env`: Central environment variables file (ignored by git).
- `.env.example`: Root template for environment variable names.
- `README.md`: Main repository documentation.
- `CONTRIBUTING.md`: Contribution guidelines for HackIT Commit Rush.
