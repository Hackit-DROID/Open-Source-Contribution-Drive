Common Issues & Solutions
Problem: Frontend shows 6 students, Backend shows 5

Cause: Browser is using old LocalStorage data instead of API

Solution: Click "Quick Fix" button above

Problem: "Failed to fetch" error

Cause: Backend server is not running

Solution: Start backend with python manage.py runserver 8001

Problem: Changes don't sync between frontend and admin

Cause: Frontend not connected to API

Solution: Clear LocalStorage and hard refresh
